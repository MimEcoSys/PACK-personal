# [PD.WP.023] Список утечек внимания

---

## Definition

**Список утечек внимания** — личный список регулярных отвлечений человека, составленный по журналу отвлечений. У каждой строки: утечка (что отвлекает — например, уведомления чата, вкладка с почтой), сколько раз в день, примерная длительность, что теряется; для одной-двух главных утечек — выбранная защита.

По роду это документ, несущий описание утечек внимания человека; его составление — работа по методу [PD.METHOD.082](../03-methods/PD.METHOD.082-attention-control.md). В практикуме S1 он назван рабочим продуктом недели; в разделе рабочих продуктов пака он учитывается как выход этой работы — по той же договорённости, что список рабочих продуктов ([PD.WP.021](PD.WP.021-work-product-list.md)).

Список утечек внимания — это НЕ:
- Журнал отвлечений: журнал — отдельные записи по времени, список — сводка повторяющихся утечек.
- Перечень запретов: список называет утечки и их цену, защита выбирается только для главных.

## Existence Criteria

| Criterion | Test |
|-----------|------|
| **Записан** | Список существует, его можно открыть |
| **Из наблюдений** | Строки опираются на записи журнала, а не на догадки |
| **Полная строка** | У каждой утечки названы частота, длительность и что теряется |
| **Защита главных** | У одной-двух главных утечек записана защита |

**Existence check**: может ли другой человек по списку понять, какие утечки у человека главные, сколько они стоят и что против них поставлено?

## Quality Criteria

| Criterion | Description | How to Verify |
|-----------|-------------|---------------|
| **Актуальность** | Список обновлён по журналу не реже раза в неделю, пока метод применяется | Дата последнего обновления |
| **Конкретность** | Утечки названы предметно («уведомления рабочего чата»), а не общо («телефон отвлекает») | Просмотреть строки |
