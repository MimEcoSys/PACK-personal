# [PD.WP.022] Документ о закрытии проекта

---

## Definition

**Документ о закрытии проекта** — записанный итог завершённого проекта. В нём четыре раздела: исход (результат получен — по какому признаку, или проект остановлен — с причиной), что сделано, какой получен результат и где он находится, что осталось открытым — с сохраняющимися обязательствами, освобождёнными ресурсами, полезными выводами и адресом передачи каждого открытого пункта.

По роду это документ, несущий описание исхода проекта; его создание — работа по методу [PD.METHOD.077](../03-methods/PD.METHOD.077-project-closing.md). В разделе рабочих продуктов пака он учитывается как выход этой работы — по той же договорённости, что список рабочих продуктов ([PD.WP.021](PD.WP.021-work-product-list.md)).

Документ о закрытии проекта — это НЕ:
- Отметка о готовности рабочего продукта: та относится к одному продукту, этот документ — к проекту целиком.
- Отчёт о проделанной работе: в нём названы результат и открытое, а не потраченные усилия.
- Сам результат проекта: документ указывает, где результат, но им не является.

Пример в практике пилота: раздел «Закрытие» в архивной карточке РП — исход, что проверено, оговорки, что осталось вне закрытия.

## Existence Criteria

| Criterion | Test |
|-----------|------|
| **Записан** | Документ существует рядом с материалами проекта, его можно открыть |
| **Исход назван** | Указано: результат получен или проект остановлен, и почему |
| **Судьба результата указана** | Полученный результат доступен по указанному адресу; при его отсутствии это явно записано и указаны сохранённые материалы |
| **Открытое передано** | У каждого открытого пункта есть адрес передачи или отметка отказа с причиной |

**Existence check**: может ли другой человек через полгода по документу восстановить, что было сделано, чем кончилось и какие хвосты остались и куда переданы?

## Quality Criteria

| Criterion | Description | How to Verify |
|-----------|-------------|---------------|
| **Своевременность** | Документ записан при завершении проекта, а не спустя месяцы | Документ датирован не позже месяца после последней работы по проекту |
| **Без хвостов без адреса** | Ни один открытый пункт не оставлен без передачи или отказа | Просмотреть раздел открытого |
